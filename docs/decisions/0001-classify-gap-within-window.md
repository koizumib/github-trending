# 0001 10日以内に間が空いて戻ってきたものは continuing にする

- 日付：2026-09-30
- 状態：決定

## 背景
設計書 §2 では continuing を「前の日から続いている」としているが、「3日前に上がり、昨日は上がらず、今日また上がった」ものの扱いが決まっていなかった。

## 決定
- 前の日から window（10日）前までに1回でも上がっていれば continuing とする
- new は「その期間に一度も上がっていない、かつ過去の記録もない」もの
- returning は「過去の記録はあるが、最後に上がったのが window より前」のもの
- 分類には「今日より前」の記録だけを使う。同じ日に2回動かしても結果が変わらない

## 理由
new の定義（過去10日に一度も上がっていない）に当てはまらないので、詳しく要約し直す必要はない。10日以内なら要約はすでにある。
