# 0003 サイトの見た目：PC では2列、グラスモーフィズム、テーマの切り替え

- 日付：2026-09-30
- 状態：決定

## 背景
M3 のサイトを本人が見て、「PC だと余白が多い」「もっと今どきの見た目（グラスモーフィズム）に」「ダークとライトを右上で切り替えたい」とのこと。

## 決定
- スマホ（幅 760px 未満）は1カラムのまま。PC では一覧のカードを2列にし、全体の幅を広げる。詳しいページは読みやすい行の長さ（約 46rem）に抑える
- 背景にぼかした色のにじみを置き、ヘッダーとカードを半透明＋`backdrop-filter` にする
- 右上のボタンでダーク／ライトを切り替える。初めは OS の設定に従い、切り替えたら `localStorage` に覚える。JavaScript はこのためだけの数行にする（設計書 §6 の「最小限」の範囲）
