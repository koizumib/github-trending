# 0004 要約に分野のタグ（tags）を足す

- 日付：2026-09-30
- 状態：決定

## 背景
本人から「カードの下にタグを付けて、どの分野のリポジトリか一目で分かるようにしたい」とのこと。

## 決定
- 要約の JSON に `tags`（必須、1〜4個）を足す。先頭が主な分野
- 語彙は固定し、`schemas/summary.schema.json` の enum を正本にする。`docs/routine.md` にも同じ一覧を載せ、テストで一致を確かめる
- GitHub の topics は使わない。付いていないリポジトリが多く、表記もばらばらで、一覧で並べたときに揃わないため
- ダークのときのカードの背景をより不透明にする（背景のにじみが文字に重なって読みにくかったため）

## あとで
語彙を固定したので、タグごとの一覧ページ（`/t/{tag}/`）を足せる。
