# 0009 サイトの見た目をシンプルにする（0003 のグラスモーフィズムをやめる）

- 日付：2026-09-30
- 状態：決定（0003 の見た目の部分を置き換える）

## 背景
本人から「デザインが微妙な気がしていた。もっとシンプルで読みやすいデザインでいい」とのこと。

## 決定
- 飾りをやめる：背景のにじみ、すりガラス（backdrop-filter）、グラデーション、影、カードが浮き上がる動きをなくす。背景は1色、カードは細い枠線だけ
- 文字を主役にする：本文と背景のコントラストをはっきりさせる。色は差し色1色（リンク、今いるタブ）だけ。順位やタグは控えめな表示
- 並べ方：スマホは1カラム。PC（幅 900px 以上）は一覧のカードを2列まで。3列は1行が短く日本語が細切れになるのでやめる。詳しいページは1カラム（約 44rem）
- 0003 のうち、ダーク／ライトの切り替え（右上のボタン、OS の設定が初期値、ブラウザに覚える）は残す
