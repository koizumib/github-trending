# 0010 サイトの見た目を新聞のようにする

- 日付：2026-09-30
- 状態：決定（0009 の見た目を置き換える）

## 背景
0009 でシンプルにしたが、本人から「もっと新聞っぽくしてもいいかも。なんか読みにくい」とのこと。読みにくさの原因は、全部が同じ大きさ・同じ太さのゴシック体で見出しと本文のメリハリがないこと、同じ形の箱が並んで目の置きどころがないこと、と考えた。

## 決定
- 書体：見出しと本文は明朝体（端末に入っているもの：ヒラギノ明朝、游明朝、Noto Serif JP など）。順位・言語・スター・タグなどの細かい情報は小さなゴシック体。Web フォントは読み込まない（日本語のフォントは重いため）
- 題字：一覧のページの一番上に、大きく日付（例：2026年9月30日（水））、その下に「GitHub Trending デイリー版」と件数。二重の罫線で区切る
- トップ記事：一覧の最初の記事（1位）だけ幅いっぱいに、大きな見出しで載せる
- 段組み：記事を箱に入れず、記事と記事のあいだを細い罫線で区切る。PC（幅 900px 以上）は2段組みで、段のあいだに縦の罫線を引く。記事は上から下へ、左の段から右の段へ流れる
- 紙の色：背景は少し温かみのある白、ダークは焦げ茶がかった黒。本文は両端揃え
- 残すもの：ダーク／ライトの切り替え、期間のタブ、タグ、詳しいページの構成
