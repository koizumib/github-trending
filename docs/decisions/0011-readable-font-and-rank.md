# 0011 フォントを BIZ UDPゴシックに、順位を大きく、タグを塗りつぶしに、ダークを無彩色に

- 日付：2026-09-30
- 状態：決定（0010 のうち、書体・記事の頭・タグ・ダークの色を置き換える。段組みや題字は残す）

## 背景
本人から次の要望があった。
- 明朝体は文字が細すぎて見にくい。もっとよいフォントを（メイリオなど）
- タグは丸角で塗りつぶしにしたい
- 順位や言語が並ぶ記事の頭を工夫したい。順位は上位ほど大きく（1位は特大、2〜3位は大、4〜5位は中）
- ダークモードの茶色は、やめてほしい

## 決定
- 書体：BIZ UDPゴシック（モリサワの、読みやすさを重視して作られた書体）を Google Fonts から読み込み、見出しも本文も使う（太さは 400 と 700）。読み込めないときの代わりは、メイリオ、ヒラギノ角ゴ、Noto Sans JP の順
  - メイリオは Windows にしか入っておらず、iPhone や Mac では使われないため、Web フォントで揃える
  - Google Fonts は必要な文字の分だけを小分けにして読み込むので、日本語でも重くなりにくい。`display=swap` で、読み込むまでは代わりのフォントで表示する
  - 0010 の「Web フォントは読み込まない」は、この1書体に限って改める
- 記事の頭：左に大きな順位の数字、右に言語（色の点つき）とスター数、その下にリポジトリ名。順位の数字は、1位は特大、2〜3位は大、4〜5位は中、6位以下は小。言語の色は、GitHub で見慣れた色に近いものを主な言語だけ持つ（ないものは灰色）
- タグ：丸角で塗りつぶし。先頭（主な分野）は少し濃く
- ダーク：茶色をやめ、青みのない黒とグレー（無彩色）にする。ライトは今の紙の色のまま
- 期間の呼び名：デイリー・ウィークリー・マンスリーを、日次・週次・月次にする。トップ（最新の日）のデイリーだけは「本日」と出す（過去の日のページで「本日」と出ると紛らわしいため）。URL（`/weekly/` など）とデータの名前（`daily`、`weekly`、`monthly`）は変えない
