# 0012 ライトモードの背景を新聞紙の色と質感にする

- 日付：2026-09-30
- 状態：決定（0010・0011 のライトの色を置き換える）

## 背景
本人から「ライトモードをもっと新聞っぽくしたい。背景を新聞のテクスチャっぽく。新聞は生成り色ではなく、少し青みがかった薄いグレーでは」とのこと。

## 決定
- 紙の色：少し青みがかった薄いグレー（`#e6e9ec` 前後）。罫線・文字・タグも同じ冷たいグレーの系統に揃える。差し色の赤は残す
- 紙の質感：背景に、ごく薄い細かなノイズを重ねる。画像ファイルは使わず、CSS に SVG（`feTurbulence`）を埋め込む。色は付けず（彩度 0）、濃さは数 % にとどめて文字の読みやすさを落とさない
- ダークモードは変えない（質感も付けない）
