# 0013 題字にロゴ「github新聞」を使い、新聞らしい装飾を洗練させる

- 日付：2026-09-30
- 状態：決定（0010〜0012 の題字と装飾を置き換える。書体・紙の色・順位の段階・タグは残す）

## 背景
本人がロゴ（`assets/logo/logo_light.png`、`logo_dark.png`。「github新聞」の題字）を用意した。「ヘッダにはこれを使い、その右上に日付を書く。新聞っぽい装飾はもっと洗練させてほしい」とのこと。

## 決定
- ヘッダ（題字の欄）：左にロゴ、右上に日付（例：2026年9月30日／水曜日）、その下に「過去の日」とテーマの切り替え。全ページ共通
  - 日付は、日ごとのページ（トップを含む）はその日、詳しいページと過去の日の一覧は最新の日
  - ロゴはライト用とダーク用を、テーマに合わせて切り替える（右上のボタンで選んだテーマにも従うよう、`<picture>` ではなく CSS で出し分ける）
  - 一覧のページの大きな日付の見出しはやめる（日付はヘッダの右上に移る）
- ロゴの画像：原本は `assets/logo/` に置く（サイトには載せない）。サイトには、透明の余白を切り詰めて横 1040px に縮め、16色のパレットにした PNG を載せる（それぞれ 10KB 前後）。作り方は `docs/operations.md` に書く
- 装飾：
  - 罫線は「太い線と細い線の組み合わせ（表罫）」と「細い線」の2種類だけにし、使う場所を絞る（題字の下、トップ記事の下、フッターの上）
  - 「■」の印はやめる
  - 期間のタブは、細い縦線で区切った文字だけ。今いる期間は太字
  - 言語とスター数は枠で囲まず、小さな文字で並べる（言語の色の点は残す）
  - 赤（差し色）は順位の数字とリンクの一部だけに使う
