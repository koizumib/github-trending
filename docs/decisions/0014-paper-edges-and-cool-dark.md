# 0014 紙面の左右に細い線、ダークを冷たいグレーに、差し色を赤に、CSS の URL に版の印

- 日付：2026-09-30
- 状態：決定（0011 のダークの色を置き換える）

## 背景
本人から次の要望があった。
- 新聞っぽく見せるため、ページの左右に細い線を入れたい（紙の切れ目っぽさ）
- ダークモードの色づかいが気に食わない。まだ茶色がベースに見える。差し色は濃いオレンジでないほうがよい

ダークの色は 0011 で無彩色にしていたが、`style.css` の URL がずっと同じなので、ブラウザが以前の茶色い CSS を覚えたまま使っている可能性がある。

## 決定
- 紙面：ヘッダ・本文・フッターを1枚の「紙」（`.paper`）で包み、その左右に細い縦線を引く。PC では紙面の幅（62rem）の端に、スマホでは画面の端から 6px 内側に引く
- ダークの色：背景は少し青みのある暗いグレー（`#15181c` 前後）、文字は冷たい白、罫線やタグも同じ系統。ライトの新聞紙の冷たいグレーと揃える
- 差し色（順位の数字など）：オレンジ寄りをやめ、オレンジを含まない赤にする。ライトは `#b3261e` のまま、ダークはローズ系の赤（`#f0647a` 前後）
- CSS とロゴの URL に、中身から作った短い印を付ける（例：`style.css?v=1a2b3c4d`）。中身が変わると URL が変わるので、ブラウザや Cloudflare が古いものを使い続けない。印は中身だけから決まるので、「入力が同じなら出力も同じ」は保たれる
