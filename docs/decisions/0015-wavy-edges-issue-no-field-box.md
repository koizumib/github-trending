# 0015 紙面の左右を波線に、号数、「本日の分野」の囲み、トップ記事の大きな1文字目

- 日付：2026-09-30
- 状態：決定（0014 の紙面の左右の線を置き換える）

## 背景
本人から次の要望があった。
- 紙面の左右の線を、ごく細かい波線にしたい。ライトの線はもう少し薄く
- フッターの横線が左右の縦線とくっついているのを直したい。フッターの横線はもう少し太く
- 新聞っぽくする案のうち、1（号数）、3（本日の分野）、5（トップ記事の飾り）を入れたい

## 決定
- 紙面の左右の線：小さな波の形（SVG）を縦に繰り返して線にする。色はテーマの色（`--edge`）を使えるよう、SVG は `mask-image` として使い、`background-color` で色を付ける。ライトの `--edge` は一度薄くしたが、本人の希望で元の濃さ（`#9ba2aa`）に戻した
- フッターの横線：本文と同じ幅の内側に収め（左右の縦線に届かない）、太さは 2px
- 号数：ヘッダの日付に「第N号」を添える。記録のある日を古い順に数え、最初の日を第1号とする（`data/daily/` の日付だけで決まる）。詳しいページと過去の日の一覧では、最新の日の号数
- 本日の分野：一覧のページのタブの下に、天気欄のような小さな囲みを置き、そのページの記事（日次は続報も含む）の要約のタグを数えて、多い順に最大6つ並べる。数が同じなら語彙の名前順。日次は「本日の分野」（過去の日は「この日の分野」）、週次は「今週の分野」、月次は「今月の分野」。要約が1つもなければ出さない
- トップ記事：1位の記事の本文の最初の1文字を大きくする（ドロップキャップ）
