# 0016 記事を左右に順に並べ、見出しを日本語の一文にする

- 日付：2026-10-01
- 状態：決定（0010 の「左の段から右の段へ流れる」並びと、記事の見出しを置き換える）

## 背景
本人から次の要望があった。
- 2段組みが「2｜9、3｜10 …」と左の段から右の段へ流れる並びではなく、「2｜3、4｜5 …」と左右に順に並べたい
- 新聞らしさの案の4（見出しを日本語の一文にし、リポジトリ名を小さな肩書きとして上に添える）を入れたい

## 決定
- 並び：PC の2段組みを CSS の段組み（columns）からグリッドに変え、記事を左 → 右 → 次の行の左 … の順に並べる。1位（トップ記事）は2段にまたがる。段のあいだの縦の罫線は、右側の記事の左の線として引く。同じ行の左右の記事は高さを揃え、下の線の位置も揃える。日次の「続報」の一覧も同じ並びにする
- 見出し：要約があるものは、`what`（何をするものかの一文）を太い見出しにする。末尾の「。」は取る。その上に、リポジトリ名を小さな肩書きとして添える（リンクは詳しいページ）。要約がないものは、今までどおりリポジトリ名を見出しにする
- 見出しが長い文になるので、順位ごとの見出しの大きさは控えめにする（順位の数字の大きさの段階はそのまま）
- 詳しいページの見出しは、今回は変えない
