# 0017 日本時間の6時より前は Discord に通知しない

- 日付：2026-10-01
- 状態：決定

## 背景
10/1 の 0時台に、サイトの見た目を直す push をしたところ、`daily.yml` の通知の段階が「今日（10/1）はまだ送っていない」と判断し、要約がほとんどない 10/1 の通知を送ってしまった。本人は「10/1 は朝の定期実行に任せる」と決めていた。日付が変わった直後の push では、この事故が起きうる。

## 決定
- `notify` は、日本時間の 6:00 より前には送らない（ログに理由を出して終わる。失敗にはしない）。手で送り直すときの `--force` だけは例外
- 6時より前に取得や要約が済んでも、通知は朝の routine の push（7時ごろ）か、9時の見張りで送られる
- 10/1 は誤って送った記録を `data/notified.json` から消し、朝に改めて送る
