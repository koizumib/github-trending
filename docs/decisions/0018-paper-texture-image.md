# 0018 ライトの紙の質感を、本人が用意した写真から作る

- 日付：2026-10-01
- 状態：決定（0012 の SVG のノイズを置き換える。紙の色はそのまま）

## 背景
本人が紙の写真（`assets/texture/paper_texture.webp`、1600×1062、青みのあるグレー）を用意し、「透明度を高くするなどして、質感っぽさだけ残るように背景に使ってほしい」とのこと。

## 決定
- 写真から質感だけを取り出す：白黒にし、大きな明暗のむら（ぼかした画像）を引いて細かな凹凸だけを残し、明るさ 128 を中心にする。横 1000px、WebP の画質 40（約 64KB）にして `src/trending_digest/static/paper_texture.webp` に置く。作り方は `docs/operations.md`
- 重ね方：紙の色（`--paper`）の上に、`mix-blend-mode: soft-light`、不透明度 0.6 で重ねる。色は付かず、明暗の凹凸だけが乗る。画面に固定し、原寸（1000px）で敷き詰める
- ダークには重ねない（`--texture-opacity: 0`）
- 原本は `assets/texture/` に置き、サイトには載せない
