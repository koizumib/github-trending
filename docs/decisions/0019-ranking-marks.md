# 0019 全件を順位どおりに並べ、順位の下に「動き」と「顔ぶれ」の印を付ける

- 日付：2026-10-01
- 状態：決定（日次の「継続は下に名前だけ」をやめる）

## 背景
本人から「継続のものを上に出さないようになっているが、出して、ちゃんとランキング形式にしてほしい。そのうえで、順位が上がった・下がった・同じ、と、前日から継続・新しくランク入り・一度圏外になって再びランク入り、が分かる印を順位の下に付けてほしい」とのこと。

## 決定
- 日次も、全件を順位どおりに記事として並べる（「継続して上がっているもの」の一覧はやめる）
- 比べる相手は、同じ期間（日次・週次・月次）の、その日より前でいちばん新しい記録（ふつうは前日）。記録のない日があっても、その前の記録と比べる
- 動き：前回もランク入りしていれば、順位の差を出す。上がったら「▲n」（赤）、下がったら「▼n」（青。日本の株価欄にならう）、同じなら「→」（灰色）
- 顔ぶれ：
  - 「続」：前回もランク入りしていた
  - 「新」：その期間の記録で、今回初めてランク入りした
  - 「再」：以前ランク入りしていたが、前回は圏外で、今回戻ってきた
- 印は順位の数字の下に、新聞の囲み文字のような四角い印（顔ぶれ）と、矢印と数（動き）で出す。印の意味は、分野の囲みの下に凡例で示す
- 版の情報の件数は「新 n・続 n・再 n」で出す
- この判定はサイトの表示だけのもの。要約の対象を決める `status`（new／continuing／returning、0001）は変えない
- 記録の初日（2026-09-30）は比べる相手がないので、全部「新」
