# 0020 題名はリポジトリ名に戻し、その下に what を短い一文で添える

- 日付：2026-10-01
- 状態：決定（0016 の「what を見出しに」を取り消す。左右に順に並べる部分は残す）

## 背景
0016 で `what` を太い見出しにしたところ、本人から「what が題名みたいになっている。あくまでリポジトリ名が題名で、その下に本当に一文だけ what を簡単に書いてほしい。今の what は長すぎて1、2行に収まらない」とのこと。

## 決定
- 記事の題名はリポジトリ名（今までどおり大きく太く）。その下に `what` を小さめの文字で添え、2行を超えた分は「…」で切る。肩書きはやめる
- `what` は30字前後の簡単な一文にする（長くても50字）。種類が分かる形（「〜する CLI」「〜のための Python ライブラリ」など）。技術の細かい説明は `tech` に書く
- Schema で `what` の長さの上限を 200字から 50字に下げ、`validate` で止まるようにする
- 要約済みの29件の `what` は、今の内容を縮める形で30字前後に書き直す（新しい情報は足さない）
- `docs/routine.md` の `what` の説明も直す
