# 0022 題名は「アカウント名/」を小さく上に、スマホは本文の行を広く、ロゴを大きく

- 日付：2026-10-01
- 状態：決定

## 背景
本人から次の要望があった。
- `アカウント名/リポジトリ名` のうち、リポジトリ名のほうが大事。題名はリポジトリ名だけを今の大きさで出し、その上に「アカウント名/」を言語名と同じ薄い色で小さく書く
- スマホでは、`what` の一文と言語・スター数の行が、題名と同じ位置から始まっていて行が短い。順位の数字と同じ位置から始め、右上の印と同じ位置まで使いたい
- スマホで「github新聞」のロゴが小さい。もっと大きく

## 決定
- 題名（一覧の記事と詳しいページ）：1行目に「アカウント名/」（`--muted` の色、小さな文字）、2行目にリポジトリ名（今の題名の大きさ）
- 記事の頭をグリッドで組む。PC（幅 900px 以上）は今までどおり、左に順位、真ん中に題名・一文・言語とスター、右上に印。スマホは、1行目に順位・題名・印を並べ、一文と言語・スター数はその下に記事の幅いっぱい（順位の左端から印の右端まで）で出す
- スマホのロゴの幅は、日付の欄に要る幅（約 150px）を残した残り（最大 300px）。日付の文字を少し小さくする
