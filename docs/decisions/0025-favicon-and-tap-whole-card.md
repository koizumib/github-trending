# 0025 favicon、「この日のページ」を消す、スマホのタブの帯を1行に、記事のどこを押しても詳しいページへ

- 日付：2026-10-02
- 状態：決定

## 背景
本人から次の要望があった。
- favicon（`src/trending_digest/static/favicon.png`）を使ってほしい
- ヘッダの下の帯の右にある「この日のページ」は消してほしい
- スマホで、タブ（本日・週次・月次）の下に件数が来ている。同じ高さに並べ、件数は右に置いて帯を低くしたい
- 今はリポジトリ名を押さないと詳しいページに行けない。順位の数字や本文を押しても行けるようにしたい

## 決定
- favicon：本人の画像は白い絵柄・透明の背景（最初は横長の 255×168、同じ日に絵柄を大きく切った 164×155 に差し替え）。明るいタブでは白が見えないので、透明の余白を足して正方形（256×256）にし、墨色版（`favicon_light.png`）と白版（`favicon_dark.png`）を作る。`<link rel="icon" media="(prefers-color-scheme: …)">` で出し分け、色の設定を読まないブラウザには墨色版を出す。原本は `assets/logo/favicon_original.png`
- 「この日のページ」のリンクを消す（過去の日の一覧からは行ける）
- タブの帯：スマホでも、左にタブ、右に件数を1行で並べる（件数の文字を少し小さくし、折り返さない）
- 要約のある記事は、記事のどこを押しても詳しいページへ行く（題名のリンクを記事全体に広げる）。要約のない記事は、今までどおり題名だけが GitHub へのリンク
