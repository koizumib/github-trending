# 0026 英字で始まる本文も書き出しを大きく、ページの題は「github新聞」（日付のページは日付付き）に

- 日付：2026-10-03
- 状態：決定

## 背景
- トップ記事（1位）の本文は、最初の1文字を大きくしている（0015）。ただし英字の1文字目だけを大きくすると単語が割れる（「**A**I」）ため、日本語で始まるときだけにしていた。本文は「AI エージェント…」のように英字で始まることが多く、日によって飾りが付いたり付かなかったりしていた。本人から「なぜ日によって違うのか」と聞かれ、そろえることにした
- ブラウザのタブに出るページの題が「2026年10月2日（金） 本日 | github新聞」と長い。本人から「日付ではなく github新聞 にしたい」とのこと

## 決定
- 書き出しの飾りは、日本語で始まるなら1文字目、英字で始まるなら最初の単語（10文字まで。末尾の「.」などは含めない）を大きくする。単語は1文字より少し小さめ（2.6em）にする。`` ` `` で始まる文と、10文字を超える単語は飾らない
- `::first-letter` ではなく、サイトを作るときに書き出しを `<span class="drop">` で囲む（`build_site.dropcap`）。CSS の `::first-letter` では単語を選べないため
- トップ（本日・週次・月次）のタブの題は「github新聞」だけにする。日付を指定したページ（`d/YYYY-MM-DD/`）は「github新聞（26/10/02）」、週次・月次はその後ろに「週次」「月次」を添える（同じ日の3ページを見分けるため）。詳しいページは「owner/name | github新聞」のまま（どのリポジトリか分かるように）
