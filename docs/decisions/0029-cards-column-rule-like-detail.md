# 0029 一覧の2段組みの罫線を、詳しいページと同じ組み方にする

- 日付：2026-10-03
- 状態：決定

## 背景
PC の一覧（2段組み）では、記事を区切る横の線が段のあいだの縦の線と交わり、表のマス目のように見えていた。詳しいページの2段組み（真ん中に縦の罫線が通り、節を区切る横の線は各段の幅だけ）の方が新聞らしい、と本人から。

## 決定
- 一覧の2段組みに段のあいだ（44px。詳しいページと同じ）を取り、記事の横の線は各段の幅だけにする
- 段のあいだの真ん中に、切れ目のない縦の罫線を通す（右の記事の左側に引き、行をまたいでつながるようにする）
- トップ記事の下の太い線と、スマホの1段の組みは今までどおり
