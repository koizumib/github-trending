# 0030 リポジトリ名と順位の数字を、英字の新聞の見出しのようなセリフ体にする

- 日付：2026-10-03
- 状態：決定（0011 の「見出しも本文も BIZ UDPゴシック」のうち、英字の見出しだけを改める）

## 背景
本人から「リポジトリ名などは、もっと新聞っぽいフォントでいい」と。リポジトリ名はいつも英字なので、日本語の明朝体（0011 で細くて読みにくいとやめた）を使わずに、英字だけのセリフ体で新聞の見出しらしくできる。

## 決定
- Google Fonts から Playfair Display（太さ 400・700・800）を足して読み込む。英字だけの書体なので軽い。読み込めないときの代わりは Georgia、Times New Roman
- 使うところ：一覧の題名と詳しいページの大きな題名（リポジトリ名は 800 の太字、「アカウント名/」は細い斜体）、順位の数字（800）、英字で始まる本文の大きな書き出し（0026）
- 細すぎて読みにくくならないよう、リポジトリ名と数字は太い字（800）を使う
- 「位」、日本語の書き出し、本文、そのほかの文字は BIZ UDPゴシックのまま
