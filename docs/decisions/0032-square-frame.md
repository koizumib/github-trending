# 0032 紙面の全体を、四角い二重の枠で囲む

- 日付：2026-10-03
- 状態：決定（0015 の紙面の左右の波線を置き換える）

## 背景
本人から、新聞っぽくするために、ページ全体（紙面）を四角い枠で囲みたい、と。

## 決定
- 紙面（ヘッダから末尾まで）を、四角い二重の枠で囲む。外は太め（2px）、3px 内側に細い線（1px）。基本データの二重の枠と同じ考え方。色は今までの紙面の線と同じ `--edge`（テーマで変わる）
- 左右の波線はやめる
- 枠の外に、スマホは上下左右 6px、PC（幅 1004px 以上）は上下 14px の余白を取り、枠の4辺が見えるようにする。中身が少ないページでも、枠は画面の下まで伸ばす
