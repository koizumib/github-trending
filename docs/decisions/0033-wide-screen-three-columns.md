# 0033 広い画面では紙面を広げて3段に組み、トップ記事の右に脇の欄を置く

- 日付：2026-10-03
- 状態：決定（0029 の一覧の2段組みは、幅 900〜1359px でそのまま使う）

## 背景
本人から、PC の横長の画面（1920px など）で見ると、紙面（約 1000px）の左右が寂しい、と。紙面を広げて3段組み／2段組みのまま右に脇の欄を足す／紙面の外を飾る、の3案から、紙面を広げて3段組みにする案を選んだ。

## 決定
- 幅 1360px 以上の画面では、紙面を 90rem（1440px）まで広げる。画面の端からは左右 14px 空ける
- 一覧は記事を3段に組む。トップ記事は左の2段分の幅。右の段の上には、トップ記事とその下の行の2行分の高さで「脇の欄」を置き、2位・3位はトップ記事の下に入る。その下は3件ずつ並ぶ
- 脇の欄の中身：そのページの分野（「本日の分野」など。末尾の囲みと同じもの）と、同じ日のほかの期間の上位5件（日次のページなら週次と月次）。1件ずつ順位、リポジトリ名、`what` の短い一文。要約があれば詳しいページへ、なければ GitHub へ。見出しから、その期間のページへ
  - 脇の欄が出る幅では、末尾の分野の囲みは出さない（同じものが2つ出ないように）
  - 判断は入らない：上位5件は、その日の記録の順位どおり
- 縦の罫線は 0029 と同じ引き方（段のあいだに通し、横の線とは交わらせない）を3段に合わせて引く
- 詳しいページの本文は3段組みにする
- これより狭い画面（スマホ、幅 900〜1359px の PC）は今までどおり。脇の欄は出さない
